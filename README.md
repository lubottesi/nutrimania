# Nutrimania

The first draft of a health and fitness site: a navbar and a hero section with an intro text and an "Explorar" button. Only the home page exists. The nav links (Academia, Nutrição, Calculadoras, Conteúdos) point to pages that weren't built.

The idea was continued as GoFit - see [gofit-oficial-oficial](https://github.com/lubottesi/gofit-oficial-oficial) for the finished version.

## Stack

- HTML5
- CSS3 (flexbox, grid, Google Fonts)

## Running locally

No build step - open `index.html` in a browser.
